ODTWORZENIE APLIKACJI 1.1.0 Z KODU — WINDOWS x64
================================================

Nie potrzeba tych narzędzi do uruchomienia dostarczonego EXE.
Poniższe polecenia są wyłącznie dla osób odbudowujących lub modyfikujących program.

Wymagany Python Windows x64 3.13.12 z pip. W PowerShell w katalogu źródła:

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install PySide6-Essentials==6.8.3 shiboken6==6.8.3 pyinstaller==6.20.0
.\.venv\Scripts\python.exe -m unittest discover -v -p test_dns_native_v1_1_0.py
.\.venv\Scripts\python.exe -m PyInstaller --onefile --windowed --noupx --clean --noconfirm --name dns_test_v1.1.0 --version-file windows_version_v1.1.0.txt --exclude-module PySide6.QtWebEngineCore --exclude-module PySide6.QtWebEngineWidgets --exclude-module PySide6.QtWebEngineQuick --exclude-module http.server --exclude-module webbrowser dns_test_v1.1.0.py

Wynik: dist\dns_test_v1.1.0.exe. Systemowa ikona PyInstaller w tej odbudowie nie
wpływa na działanie. Dodaj własny plik ICO przez --icon, jeżeli chcesz inną ikonę.

Kod nie importuje poprzedniej wersji aplikacji. Zgodne wersje bibliotek można
wymieniać i odbudowywać EXE; należy ponownie wykonać testy.
Podpisu wydawcy nie tworzy żadne z tych poleceń.
